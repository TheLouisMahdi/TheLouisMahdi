# Windows 7 wallpapers

This folder contains the 37 wallpaper files used by the standard Windows 7 Aero theme gallery on a United States installation: Windows 7, Architecture, Characters, Landscapes, Nature, Scenes, and United States.

The images were originally distributed with Microsoft Windows 7 and remain the property of Microsoft and their respective photographers or licensors. They are included here only as visual assets for a non-commercial Windows 7 interface simulation and are not relicensed by this repository.

Collection source: <https://github.com/bartekl1/windows-ui-assets/tree/main/Wallpapers/Windows%207>

The `thumbnails` directory contains web-optimized previews generated from the original 1920 × 1200 files. The simulator loads the previews in galleries and keeps the original files for full-screen viewing and desktop backgrounds.
